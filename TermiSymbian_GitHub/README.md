# TermiSymbian 🚀

Symbian S60v5 (Nokia C5-03 vb.) dokunmatik cihazlar için geliştirilmiş, J2ME tabanlı hafif ve sanal Linux terminal simülatörü.

## 📱 Özellikler
- Dokunmatik ekran destekli kullanıcı arayüzü.
- Temel Linux komut simülasyonları (`uname -a`, `whoami`, `ls`, `clear`, `echo`, `help`).
- Düşük kaynak kullanımı ve çökmesiz yapı.

## 🛠️ Derleme ve Kurulum
Bu proje **NetBeans** ve **Maven** kullanılarak Java ME (MIDP 2.0 / CLDC 1.1) standartlarında derlenmiştir.

### Telefona Doğrudan Kurmak İçin:
1. Releases sekmesinden en güncel `.jar` dosyasını indirin.
2. Bluetooth veya kablo ile Nokia cihazınıza aktarın.
3. Dosya Yöneticisi üzerinden `.jar` dosyasına tıklayarak kurulumu tamamlayın.
